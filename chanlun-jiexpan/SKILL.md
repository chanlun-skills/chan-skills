# 缠论大盘解盘（chanlun-jiexpan）

## 何时使用

- 用户学习缠论**大盘（指数）分析**方法：缠师如何在 2006-2008 年用中枢、背驰、区间套、比例线判断大盘走势
- 用户问"缠师当年在 530 印花税暴跌/6124 见顶/2008 熊市时是怎么说的"
- 用户想按日期检索缠师某一天的解盘原文（如 2007-05-30、2007-10-16）
- 用户想系统复盘 6 个关键时段的大盘演化（体系成型→牛市主升→见顶→熊市→筑底）
- 用户想研究"小康跌幅""中字头两个翅膀""扬抑大扬大抑"等缠师标志性表述的出处与语境

**严格不适用**：用户询问**当前或未来**大盘走势、点位预测、该不该抄底/逃顶。此时只回答方法论知识（缠师的分析框架本身），明确声明本技能只含 2006-2008 年历史数据，不做当前行情判断。

## 核心知识（先读这里）

### 6 个关键时段（key_periods.json，复盘大盘的主线）

| 时段 | 主题 |
|---|---|
| 2006-02 ~ 2006-12 | 体系成型与 1000 点筑底期 |
| 2007-01 ~ 2007-05 | 牛市主升与比例线推演 |
| 2007-06 ~ 2007-09 | 震荡筑平台与比例线压力位 |
| 2007-10 ~ 2007-12 | 6124 见顶与全年展望 |
| 2008-01 ~ 2008-05 | 熊市第一、二阶段 |
| 2008-06 ~ 2008-12 | 2284 筑底与反弹定级 |

每个时段内含 8-9 篇关键文章（标题 + 日期 + 原文），是学习"缠师如何看大盘"的最佳路径。

### 标志性表述（检索入口）

- "小康跌幅"：2007-11-12 缠师宣布的下跌空间命名体系（小康/全面小康/初步富裕/中等发达/现代化 = 1000/1500/2000/2500/3000 点）
- "两个翅膀"：中字头 + 低价股组合论述（2007-10-28）
- "扬抑大扬大抑"：2008 年行情节奏展望（cs_1099 语境）
- 比例线 / 区间套 / 中阴阶段：大盘结构判断的三大工具

## 工作流程

1. **定位数据**：读 `references/index.md` 数据地图
2. **检索**：优先运行 `scripts/search_jiexpan.py`（见下）；需要精读某时段 → 读 `key_periods.json`
3. **输出**：按"缠师原话（引用块 + 日期 + 来源）→ 结构判断拆解（级别/中枢/背驰/比例线）→ 教学点评"结构；所有表述用过去时
4. **附加声明**：结尾必须附免责声明

## 检索脚本用法

```bash
# 库统计（按年份/来源分布）
python scripts/search_jiexpan.py --stats

# 按日期检索解盘（精确日 / 年份 / 区间）
python scripts/search_jiexpan.py --date 2007-05-30
python scripts/search_jiexpan.py --year 2008 --top 15
python scripts/search_jiexpan.py --from 2007-10-01 --to 2007-10-31

# 关键词全文检索（标题 + 正文）
python scripts/search_jiexpan.py --keyword 小康跌幅
python scripts/search_jiexpan.py --keyword 比例线 --year 2007

# 六个关键时段及各段关键文章
python scripts/search_jiexpan.py --key-periods

# 文库目录检索（按标题关键词 / 大盘相关度：高度相关/相关/一般）
python scripts/search_jiexpan.py --catalog --keyword 解盘
python scripts/search_jiexpan.py --catalog --relevance 高度相关
```

## 输出规范

- 引用缠师解盘原话用引用块 `>`，标注日期与来源（时间线 / 论坛镜像 / 官方博客）
- 结构拆解明确标注级别（1分/5分/30分/日/周/月）与工具（中枢/背驰/区间套/比例线/分型）
- 涉及点位一律表述为历史（"当时缠师指出 6124 点……"），禁止"换算到今天"式的对照
- 引用"小康跌幅""两个翅膀"等表述时给出原始出处日期，避免以讹传讹
