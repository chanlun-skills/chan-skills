# 缠论佛学与禅宗（chanlun-chan-zen）

收录缠中说禅（缠师）全部佛学禅宗相关内容，按「博客专栏 + 论语详解 + 回复区 + 论坛讨论」四层组织。

## 数据概览

主语料 `references/data/corpus.json`：**7,131 条 / 约 134 万字**，全部带标题、日期、来源与原文。

| 分类 | 条数 | 内容 |
|---|---|---|
| 论坛·跟帖 | 4,502 | 缠师博客原文镜像 4,389 + 缠论进阶 113 |
| 博客·论语详解 | 949 | 《论语》详解全系列（儒释会通主战场） |
| 博客·禅宗专栏 | 917 | 缠非缠禅非禅 196 / 教你打坐 428 / 禅宗辨微 137 / 禅余随笔 156 |
| 博客·兜率天连载 | 666 | 禅定与瑜伽解脱理论连载 |
| 博客·回复区 | 97 | 缠师本人回复 46 + 网友跟帖 51 |

每条记录字段：`id, cat, sub, title, date, source, url, text, is_head, seq`。

辅助数据：

- `references/data/buddhist_index.json` — 2,355 篇文档的佛学概念索引，按「佛典经藏 / 禅宗术语 / 生死哲学 / 修行实践 / 典籍人物」等词组统计词频，可做主题定位
- `references/data/corpus_meta.json` — 禅宗专栏 83 篇的篇目清单（标题/日期/系列/slug）
- `references/report/佛学禅宗内容汇总.md` — 十大主题综述 + 核心原文摘引（绝对否定与不立一法、儒释道关系、生死与灵魂等）
- `references/report/论坛佛学争鸣速览.md` — 论坛 77,725 条楼层中 1,471 条佛学楼层，按 12 个议题组织（儒释道关系 580 / 生死与灵魂 273 / 经论与义理 244 / 南怀瑾批判 118 / 真修与假修 111 / 轮回六道 99 等）
- `references/series/` — A~H 七套人工整理的系列汇编（禅宗专栏全文、教你打坐全集、禅宗辨微、兜率天连载、经文类文本、论语详解佛学段落、缠师回复与网友讨论佛学篇）
- `references/site/index.html` — **离线检索站点**：浏览器直接打开，支持全文搜索（分片加载）、分类树浏览、人物关系图谱（relations.html）、关于页（about.html）

## 使用流程

1. 用户问禅学概念/主题 → 先查 `references/report/佛学禅宗内容汇总.md` 对应主题综述，再定位原文条目
2. 用户问具体篇目（如"教你打坐第 N 篇"）→ 用检索脚本按 sub+关键词定位，或查 corpus_meta.json 篇目清单
3. 用户问论坛争论（如"网友怎么看轮回"）→ 查 `references/report/论坛佛学争鸣速览.md` 对应议题
4. 需要全文浏览/搜索界面 → 让用户打开 `references/site/index.html`
5. 引用原文一律保留标题与日期，注明出自本库

## 检索工具

```bash
# 总览统计（分类分布、字数、时间范围）
python scripts/search_chanzen.py --stats

# 按分类/子系列浏览
python scripts/search_chanzen.py --cat "博客·禅宗专栏" --sub "教你打坐" --top 10

# 全文关键词检索（标题+正文）
python scripts/search_chanzen.py --keyword 缠非缠 --top 5
python scripts/search_chanzen.py --keyword 打坐 --cat "博客·禅宗专栏" --top 5

# 按日期/区间检索（格式 2006-02-01）
python scripts/search_chanzen.py --date 2006-02-01
python scripts/search_chanzen.py --from 2006-02-01 --to 2006-03-01 --top 10

# 佛学概念索引（按概念词组定位相关篇目）
python scripts/search_chanzen.py --topics
python scripts/search_chanzen.py --index --keyword 缘起 --top 5
```

## 输出规范

1. 引用缠师原文时保留完整标题与发表日期，长文摘引控制在 500 字以内并注明出处
2. 区分缠师本人原文、缠师回复、网友跟帖三种性质——不得把网友观点混作缠师观点（回复区条目和论坛争鸣速览中已标注发言人）
3. 涉及对具体人物（如南怀瑾）的批判性讨论，仅作史料呈现，不添加评价、不主动扩散
4. 宗教哲学内容保持中立客观的学术呈现，不作宗教宣传、不提供修行指导、不评价任何宗教本身
5. 本库内容与股票投资完全无关，不得将其用于任何投资建议场景

## 合规红线

- **版权**：缠师文字版权归其权利人所有，本库仅作学习研究之用。对外发布引用时控制摘引篇幅，完整文库不随 skill 之外二次分发
- **宗教内容**：禅宗义理讨论属哲学文化范畴。AI 引用时保持中立转述，不进行宗教劝导，不将缠师观点包装为"权威修行法门"
