# 数据地图与检索指南

> 本目录是 chanlun-case-library 的全部数据层。AI 使用前请先读本文件。

## 一、数据来源与原则

数据来自缠中说禅（缠师，本名李彪）2006-2008 年间的新浪博客、缠师讲坛论坛、《教你炒股票》108 课系列及图解例析，另含少量 2002-2004 年博客案例。汇编遵循三原则：

1. **原文优先**：所有案例直接摘自缠师原始发言或经其本人回复确认的问答，不做演绎性改写
2. **可回溯**：每条案例保留日期、来源渠道、原文出处
3. **不加工**：只做检索、归类与索引，不把缠师未说过的观点嫁接到具体个股上

## 二、文件清单与用途

| 文件 | 行数/规模 | 关键列 | 什么场景读它 |
|---|---|---|---|
| `汇编总览.md` | 9 章 | — | 需要方法论背景、实盘组合代号还原、图解教学案例清单、行业/年度分布时 |
| `六大经典案例.md` | 6 例 | — | 用户想深入理解某类结构的经典范本时（买卖点推演/阻击建仓/底分型/成本归零） |
| `data/个股清单.csv` | 347 行 | 排名,代码,名称,行业,案例数,起始日期,结束日期 | 需要全部个股概览、按案例数/行业排序时 |
| `data/案例明细.csv` | 3,026 行 | 日期,股票代码,股票名称,内容类型,来源渠道,来源标题,原文摘录 | 按个股/关键词检索具体案例原文（主力检索表） |
| `data/个股案例档案.csv` | 3,026+ 行 | 代码,名称,行业,案例数,起止日期,序号,案例日期,内容类型,来源渠道,来源标题,原文摘录 | 需要某只个股的完整档案视图时 |
| `data/重点个股时间线.csv` | ~1,000+ 行 | 代码,名称,行业,案例数,时间跨度,操作类型,日期,来源栏目,来源标题,原文摘录 | 需要某股"买入→持有→卖出"操作脉络时 |
| `images/配图索引.json` | 1,385 条 | title,file,codes,size | 需要查找某话题配图时（原图包需另下载） |

## 五、检索配方

1. **"XX股票缠师怎么说"** → `python scripts/search_cases.py --code <代码>`，或 grep `案例明细.csv`
2. **"三买/背驰/底分型的案例"** → `--keyword 底分型` 全文检索，再交叉读 `六大经典案例.md` 对应章节
3. **"缠师重仓/代号还原"** → `汇编总览.md` 第三章（汉奸=600607、山东人=600777、老8股、16 只等）
4. **"某股完整操作脉络"** → `--timeline <代码>` 读时间线表，按日期排序
5. **"按行业找案例"** → `data/个股清单.csv` 按行业列筛选，再回到明细表检索

## 六、数据局限

- 部分案例日期为空（来源为论坛帖子，日期缺失），检索时注意
- 部分个股名称已变更或退市（如 ST 股），以 CSV 中的历史名称为准
- 配图原图不随库分发，索引中的 codes 字段标注了关联个股代码
- 摘录保留了原文语境（含上下文重复），引用时请截取与问题相关的片段
