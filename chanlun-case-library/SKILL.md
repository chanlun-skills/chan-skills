# 缠论案例大全（chanlun-case-library）

## 何时使用

- 用户在学习缠论，想看某类结构（分型、笔、中枢、背驰、三类买卖点）在**历史行情**中的真实案例
- 用户想了解缠师在博客/论坛中对某只**历史个股**（如 600050、600737、000938、580989 等）的原话与判断
- 用户想按行业、按年度、按内容类型浏览缠论案例的分布
- 用户想做缠论教学素材整理、结构复盘练习
- 用户问"缠师当年是怎么分析某某股票的"这类**历史复盘**问题

**不适用**：用户询问任何**当前**市场该怎么操作、该买什么——此时只回答方法论知识，不引用案例做任何操作暗示，并说明本技能仅覆盖 2002-2008 年历史。

## 工作流程

1. **定位数据**：先读 `references/index.md` 了解数据地图，再按下表选择文件
2. **检索案例**：
   - 按个股检索 → 优先运行 `scripts/search_cases.py`（用法见下）
   - 按主题深读 → 读 `references/汇编总览.md`（方法论、组合代号、图解教学案例）或 `references/六大经典案例.md`
3. **组织输出**：按"案例背景 → 缠师原文摘录（引用块）→ 技术要点拆解（分型/笔/中枢/背驰/买卖点）→ 教学点评"的结构回答
4. **附加声明**：每次输出结尾必须附上本文件末尾的免责声明

## 检索脚本用法

```bash
# 列出案例数最多的个股
python scripts/search_cases.py --list --top 10

# 按代码检索某股全部案例
python scripts/search_cases.py --code 600050

# 按名称模糊检索
python scripts/search_cases.py --name 茅台

# 按内容类型过滤（可选值：原文教学图解案例/解盘实战案例/论坛回复与图解例析/博客原文个股论述）
python scripts/search_cases.py --code 000938 --type 论坛回复与图解例析

# 全文关键词检索（在原文摘录中搜索）
python scripts/search_cases.py --keyword 底分型 --top 15

# 查看某股操作时间线
python scripts/search_cases.py --timeline 600737
```

## 输出规范

- 引用缠师原文时使用引用块 `>`，并标注来源渠道与出处文件（如：论坛/缠师讲坛 cs_1037）
- 技术拆解时明确标注：级别（1分/5分/30分/日/周）、结构要素（分型/笔/线段/中枢/背驰/买卖点类型）
- 案例均为历史，叙述一律用过去时："缠师当时指出……""该股 2007 年……"
- 不做任何"如果现在""放在今天"式的操作推断

## 合规红线（必须遵守）

1. 本库全部内容定位为**技术理论教学与历史复盘**，不是投资咨询
2. **禁止**输出任何当前市场标的的买卖建议、点位预测、仓位建议
3. **禁止**以"缠师当年说 X 股票会涨"的方式暗示任何当前标的
4. 每次输出结尾附加免责声明

## 免责声明（每次输出结尾必须附加）

> 本内容仅为缠论技术理论学习与 2002-2008 年 A 股历史行情复盘，不构成任何投资建议。
