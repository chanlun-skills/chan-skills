## 三、案例的五维分类（facets）

1. **缠师态度**：确认 / 否认 / 讨论 —— 最关键维度，引用时必须区分
2. **构成形态**：标准三段回抽 / 奔走式 / 三段 30 分钟回拉 / 第一次回抽 / 盘整背驰转化 / 三角形 5 段回拉 / 回调后启动
3. **中枢命运**：新生 / 扩张 / 延续（依第 21 课"三买与中枢三命运"）
4. **涨幅档位**：≥100% / 50%–100% / <20% / 不适用（仅对确认案例赋档）
5. **级别**：日线 / 周线 / 15 分钟

## 四、检索配方

1. **"三买怎么判定"** → SKILL.md"核心知识"节 + `--chain`
2. **"缠师确认的三买有哪些"** → `--cat 确认`
3. **"什么样的不是三买"** → `--cat 否认`（福建高速时间跨度反例、复星医药重叠反例、浙江医药方法论纠错）
4. **"三买定理原文"** → `--quotes --theme 定义`（q001 第三类买卖点定理、q002 ZG/ZD 数学定义、q003 中枢三命运）
5. **"课程间表述矛盾"** → `--quotes --theme 判定` 中的 q100-q111"形式之争"，缠师最终结论 q110
6. **"某股当年是不是三买"** → `--code <代码>`，注意区分确认/否认
7. **"涨停名单"** → library.json 的 `list0116`（首行为 600068 葛洲坝，不是 600608）

## 五、数据口径

- 行情来源：东方财富历史行情接口，**不复权**（fqt=0）日线
- 基准 = 买点日收盘价；`rN` = 买点日后第 N 个交易日收盘涨幅；`max_gain` = 区间最高价相对基准的最大涨幅；`max_draw` = 区间最低价相对基准的最大跌幅
- 涨停名单基准日统一为 2007-01-16 收盘
- 涨幅档位仅对三买确认案例赋档，否认/讨论类标"不适用"

## 六、已知订正（引用前必读）

1. **北辰实业 11/14 三买**：流传 PDF 误记代码为 600832 东方明珠，应为 **601588 北辰实业**（当日行情与原文截图图注逐项吻合）
2. **000803 三卖年份**：应为 **2006-01-20**（非 2007，实测仅 2006 年对得上"大幅度跳水"）
3. **涨停名单首行**：原话"600608(600068)"，括号内代码在传抄中丢失——实际涨停的是 **600068 葛洲坝**（2007-01-16 收 4.02 元，+10.1% 涨停；600608 当时停牌无交易数据）
