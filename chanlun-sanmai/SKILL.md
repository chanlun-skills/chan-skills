# 缠论三买汇集（chanlun-sanmai）

## 何时使用

- 用户学习缠论**第三类买卖点**，想看判定方法、判定链条、原文定义
- 用户问"缠师确认过的三买案例有哪些""某只股票当年是不是三买"
- 用户想看三买案例的**历史行情复测**（买点后 10/20/60/120 日涨幅，均为 2006-2008 历史）
- 用户想了解三买"形式之争"（课程 20/21/23/36/37/92 的表述差异及缠师最终结论）
- 用户想核对流传资料中的常见错误（代码误记、年份误记）

**不适用**：用户询问**当前**市场如何操作、找三买标的——只讲判定方法论与历史案例，不做任何操作暗示，并说明本技能仅覆盖 2006-2008 年历史。

## 核心知识（先读这里）

### 三买判定链条（缠师第 20 课体系，5 步）

1. **日线中枢** —— 先有日线级别走势中枢，区间 [ZD, ZG]（数学定义，不是"横盘平台"俗称）
2. **次级别向上离开** —— 一个 30 分钟级别走势类型向上离开该中枢
3. **次级别回试** —— 以 30 分钟级别走势类型回试（日线可见三段，每段日 K 至少三根以上重合）
4. **回试低点确认** —— 回抽低点确认要看 5 分钟背驰，**必须三个级别共同来才可以**
5. **不破 ZG** —— 回试低点不跌破中枢上边缘 ZG，构成第三类买点；且**必须是第一次回抽**

缠师对工行 12/14 的原话："那天 14.40 左右刚好完成这三段 5 分钟的走势类型，你可以精确地找到 4.2 元的买点。"

### 涨幅规律（历史复测，12 条确认案例全部验证）

- 缠师原话："一般第三类买点突破，都有至少 20% 以上的涨幅"
- 复测：12/12 区间最大涨幅 ≥20%，最低 +59.0%（工商银行），最高 +266.7%（一汽解放），≥100% 有 7 条
- 关键发现：12 条中 10 条中枢命运为"新生"——**回抽不破 ZG 只是必要条件，爆发力来自"中枢新生"**

### 形式之争（易混淆点，引用时注意）

课程 18/27/36/37/92 对三买构成形式表述不一；缠师 2008-01-08 解盘明确"第三类买卖点可以是盘整+盘整形式"，最终结论："上述 2 种结论基本上是一样的，应用时综合使用即可"。详见原话库"判定"主题 q100-q111。

## 工作流程

1. **定位数据**：读 `references/index.md` 数据地图
2. **检索**：优先运行 `scripts/search_sanmai.py`（见下），或按需读参考文件
3. **输出**：按"缠师原文（引用块 + 出处编号）→ 判定要点 → 历史复测数据（标注为历史回测）→ 教学点评"结构
4. **附加声明**：结尾必须附免责声明

## 检索脚本用法

```bash
python scripts/search_sanmai.py --list                       # 全部 20 条案例一览
python scripts/search_sanmai.py --cat 确认                   # 缠师确认的三买
python scripts/search_sanmai.py --cat 否认                   # 缠师否认/纠错的（教学价值高）
python scripts/search_sanmai.py --code 601398                # 某股案例
python scripts/search_sanmai.py --form 奔走式                # 按构成形态筛选
python scripts/search_sanmai.py --fate 新生                  # 按中枢命运筛选
python scripts/search_sanmai.py --quotes --theme 判定        # 三买原话库（定义/判定/形态/操作/风险/教学）
python scripts/search_sanmai.py --chain                      # 五步判定链条
python scripts/search_sanmai.py --stats                      # 库统计概览
```

## 输出规范

- 引用缠师原话用引用块 `>`，标注出处编号（如 L20 = 教你炒股票20）
- 涉及涨跌幅一律标注"历史复测（2006-2008，东方财富不复权日线）"，不得表述为对未来收益的预测
- 引用案例时注意缠师态度维度：确认 / 否认 / 讨论 三类必须区分，**否认类案例不得当作三买范例引用**
- PDF 原件中的代码错误（600832→601588 北辰实业、000777→600784 等）以核实报告订正为准

## 合规红线（必须遵守）

1. 本库全部内容定位为**技术理论教学与历史复盘**，不是投资咨询
