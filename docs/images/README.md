## 🔁 群二维码到期更新流程（7 天一次）

**目标**：只覆盖一张图，README 与 `docs/join.html` 的链接**永远不用改**。

```bash
# 1. 把新的群二维码图片覆盖到这里（文件名必须一致）
docs/images/qun-qrcode.png

# 2. 提交推送
git add docs/images/qun-qrcode.png
git commit -m "chore: 更新群二维码（有效至 MM-DD）"
git push origin main
```

**三种更新方式（由省事到麻烦）**

| 方式 | 操作 | 适合 |
|---|---|---|
| A. 让我处理 | 把新图发我，我裁边、覆盖、提交、推送 | 最省事，推荐 |
| B. GitHub 网页替换 | 仓库 → `docs/images/` → 上传同名 `qun-qrcode.png` → Commit | 你在电脑前、图已存本地 |
| C. 自己命令行 | 上面的三条命令 | 熟悉 git |

**⚠️ 只覆盖 `qun-qrcode.png` 一个文件**：如果新建了 `qun-qrcode-2.png` 之类的新名字，README 和加群页不会自动跟着变，就得改代码了。

**⚠️ 图片自带有效期文字**：企业微信生成的图底部会印「该二维码 MM月DD日前有效」，访客一眼能看到，建议保留不要裁掉。

> 💡 **更彻底的解法**：企业微信的**普通群二维码**才是 7 天有效；管理后台的「客户联系 → 加客户 → 加入群聊」生成的是**永久活码**（一个码最多关联 5 个群，群满自动建新群）。能用活码就不用再折腾换图。
