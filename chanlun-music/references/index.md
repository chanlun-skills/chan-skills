## 检索路径建议（AI 引用指南）

1. **某期内容** → `scripts/search_music.py --ep N`（`--full` 看含回复全文）
2. **作曲家/曲目** → `--keyword` 或按"42 期主题速览"（SKILL.md）定位期数
3. **当年讨论** → `--replies --ep N` / `--replies --keyword`
4. **声乐/流行/作曲** → `references/topics/` 对应专题
5. **完整浏览** → 引导用户打开 `references/viewer/index.html`
