# 缠师周末音乐会（chanlun-music）

收录缠中说禅 2006-07-21 至 2007-08-25 在博客举办的「网上周末音乐会」全部 42 期档案——
中文互联网最早的系统性古典音乐网络连载之一。

## 数据概览

| 内容 | 数量 | 位置 |
|---|---|---|
| 音乐会期数 | 42 期（2006-07 ~ 2007-08） | `references/episodes/` 逐期原文 |
| 博客回复 | 7,149 条（有实质内容 6,292 条），缠师本人 141 条**仅存签名与时间，正文在源存档中缺失** | `references/data/全部回复.csv` |
| 音乐与唱歌专题文章 | 声乐技术、流行音乐评论、缠师作曲录音等 | `references/archive/音乐与唱歌专题档案.md` |
| 专题汇编 | 6 类（主系列/声乐/流行/作曲/跨界/前奏） | `references/topics/` |
| 期数索引 | 期号、标题、日期、回复数、缠师回复数、原帖链接 | `references/data/索引.csv` |
| 离线查看器 | 4 个自包含 HTML（主界面/音乐页/专题页/长稿页） | `references/viewer/index.html` |

数据来源：新浪博客原始存档（GitHub 镜像 alsotang/chzhshch）、缠师讲坛论坛 chanluntan.com、存档站 chzhshch.blog。

## 使用流程

1. 用户问某期音乐会 → `--ep N` 取逐期原文（节目单、乐评、缠师当年引言）
2. 用户问作曲家/曲目 → `--keyword` 全文检索分期与专题，或先看 42 期主题速览定位期数
3. 用户问当年网友讨论 → `--replies --ep N` 或 `--replies --chan`（只看缠师 141 条回复）
4. 用户问声乐/唱歌技术、流行音乐评论、缠师作曲 → 查 `references/topics/` 对应专题与 `音乐与唱歌专题档案.md`
5. 引用原文保留期号、标题与发布日期

## 检索工具

```bash
# 总览统计
python scripts/search_music.py --stats

# 42 期节目单列表
python scripts/search_music.py --list

# 某期原文（含节目单、乐评、当年回复精选）
python scripts/search_music.py --ep 5
python scripts/search_music.py --ep 42 --full        # 输出完整原文

# 关键词检索（分期原文 + 专题汇编）
python scripts/search_music.py --keyword 冬之旅
python scripts/search_music.py --keyword 男高音 --top 10

# 回复库检索（7,149 条）
python scripts/search_music.py --replies --ep 12                # 某期全部回复
python scripts/search_music.py --replies --chan --top 20        # 缠师本人回复（仅存签名，正文缺失）
python scripts/search_music.py --replies --keyword 卡拉扬        # 全库关键词

# 音乐专题清单（6 类专题的文章列表）
python scripts/search_music.py --topics
```

## 输出规范

1. 引用缠师乐评保留期号与日期；单篇摘引控制在 500 字以内并注明出处
2. 区分缠师原文、缠师回复、网友讨论三种性质——注意**已知数据局限**：缠师的 141 条回复在源存档中
   仅存签名与时间戳，正文内容缺失，AI 引用时不得编造缠师回复内容，只可如实说明"回复内容未存档"，
   缠师的乐评观点以 42 期原文为准；缠师的犀利乐评（如对卡拉扬、流行歌手的评价）属其个人观点，
   转述时明确标注，不添加评价、不主动扩散
3. 部分期标题含缠师特有的粗粝修辞，引用时保留原貌但需按上下文准确转述其音乐观点
4. 音频文件不随本库分发：当年网页播放器已失效，曲目均为公版古典音乐录音，
   现代版本请用户自行通过正规音乐平台聆听
5. 本库内容与股票投资完全无关，不得用于任何投资建议场景

## 合规红线

- **版权**：缠师文字版权归其权利人所有，本库仅作学习研究之用。古典乐曲本身（乐谱）属公版，
  但具体录音版本有各自版权，本库不收录、不分发任何音频文件
- **人物评论**：对具体歌手/指挥/公众人物的批判性乐评仅作 2006-2007 年网络史料呈现，
  标注日期与出处，不作人身攻击性传播
- **内容分级**：部分期数标题与行文含缠师风格的粗粝表达，对外传播时注意平台内容规范，
  AI 转述时聚焦音乐本体观点
