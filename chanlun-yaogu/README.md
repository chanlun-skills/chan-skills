# chanlun-yaogu · 妖股年鉴

> A股 1990-2026 年度妖股日线实算库：37 年 · 444 条明细 · 420 组日线 · 40 条修正榜

把 1990-2026 年 A 股每一年的妖股，统一用「日线谷→峰最大涨幅」口径重新测量一遍，
作为缠论 × 江恩 复盘时的客观素材。与「缠论案例大全」「三买汇集」互补：
前两者看缠师当年怎么解个股，本库看全市场每年最强的那些股票**客观涨了多少**。

## 核心口径（v5 · max draw-up）

- **定义**：窗口内「谷底日不晚于峰值日」的最大涨幅；谷取日线最低价，峰取日线最高价
- **双窗口取大**：跨年窗口 `(Y-1)-09-01 ~ Y-12-31` 与年内窗口 `Y-01-01 ~ Y-12-31`，取涨幅更大者
- **复权**：腾讯不复权日线为唯一源，自建后复权因子（gap≥1.12 且 |收/开−1|≤5% 判定除权）
- **校验**：新浪×腾讯双源交叉 366 只中 358 只完全一致；负价格 0 / 除权连续性异常 0
- **已废除口径**：年内极值（峰值早于谷底）——实为"先涨后跌的跌幅"，方向矛盾

## 使用示例

**对话式：**

- "2015 年最强妖股是哪些？" → 暴风科技 3,368%（年内谷→峰）等 Top12 + 年度综述
- "暴风科技当年涨了多少？" → 3,368%，谷 2015-03-24 的 9.43 元 → 峰 2015-05-21 的 327.01 元
- "为什么网上说浦东大众 1994 年只涨 51%？" → 修正榜解答：51% 是年度收盘涨幅，实算跨年谷→峰 552%
- "重组借壳类妖股历年有哪些？" → 141 条按涨幅排序
- "1990 年深发展涨了多少？" → 未覆盖：行情源无有效数据，仅有原始记载 +2114%

**命令行：**

```bash
python scripts/search_yaogu.py --stats              # 总览（KPI/题材/数据质量）
python scripts/search_yaogu.py --years              # 37 年一览
python scripts/search_yaogu.py --year 2015          # 某年详情
python scripts/search_yaogu.py --top 20 --from 2010 # 涨幅排行
python scripts/search_yaogu.py --theme 重组借壳      # 按题材
python scripts/search_yaogu.py --code 300431        # 按代码
python scripts/search_yaogu.py --caliber            # 口径全文
python scripts/search_yaogu.py --fix                # 修正榜
python scripts/search_yaogu.py --uncovered          # 未覆盖 24 条
python scripts/search_yaogu.py --kline "2015|300431" # 日线谷峰指标
```

**离线查看器**：浏览器直接打开 `references/viewer/妖股年鉴_1990-2026.html`。

## ⚠️ 使用边界

- **全部内容为历史走势事后复盘**，涨幅为实算值、不可复制，**不构成任何投资建议**
- 禁止据此推荐当前个股、预测未来妖股、给出买卖点
- 引用数字必须带年份 + 口径标签（跨年/年内）+ "历史实算"性质说明
- 24 条未覆盖条目不得编造实算涨幅；年份卡中带"无谷→峰"标签者同属未测算
- 数据源为腾讯/新浪日线，未经审计，仅供参考
