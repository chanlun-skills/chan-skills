# 妖股年鉴（chanlun-yaogu）

A股 1990-2026 年历年妖股统一口径实算库。与「缠论案例大全」「三买汇集」互补：
前者看缠师当年怎么解个股，本库看全市场每年最强的那些股票**客观涨了多少**。

## 核心口径（v5 · max draw-up）——引用数据前必须先讲清

1. **定义**：取窗口内「谷底日不晚于峰值日」的最大涨幅。谷取日线**最低价**，峰取日线**最高价**，
   遍历所有「先谷后峰」组合取最大者
2. **主窗口**：`(Y-1)-09-01 ~ Y-12-31`（跨年，捕捉完整主升浪）；**兜底窗口**：`Y-01-01 ~ Y-12-31`（年内）
3. **取大原则**：两窗口均成立取涨幅更大者；都不成立 → 标"未测算"
4. **口径标签**：`跨年`（谷底在前一年 9 月后）/ `年内`（谷底在当年）
5. **同日兜底**：若同一交易日「最低→最高」振幅严格大于所有跨日组合则采用同日解（实测仅 1 条：2007|600629 ST棱光）
6. **已废除口径**：`年内极值（峰值早于谷底）`——该口径实为"先涨后跌的跌幅"，方向自相矛盾且图上"谷在峰右"
7. **复权**：唯一数据源腾讯不复权日线；自建后复权因子 = ∏gap（gap = 前收/当日开盘，除权判定 gap≥1.12 且 |收盘/开盘−1|≤5%）
8. **数据校验**：负价格 0 / 除权点连续性异常 0 / 新浪×腾讯交叉验证 366 只中 358 只完全一致（97.8%）
9. **数据质量**：420 条已测算（自建后复权 419 + 新浪原始 1），24 条未覆盖；跨年 223 / 年内 197

> 引用任何涨幅数字时**必须同时给出**：股票名 + 年份 + 涨幅值 + 口径标签（跨年/年内）+ "历史实算"性质说明。

## 使用流程

1. 问某年妖股 → `--year 2015` 取年份卡 + Top12
2. 问某只股票 → `--code 300431` / `--keyword 暴风` 取该股历年记录与谷峰指标
3. 问题材分布/某题材历年 → `--theme 重组借壳`
4. 问全库排行 → `--top 20`
5. 问口径/为什么和网上数字不一样 → `--caliber` + `--fix`（40 条修正榜正是解答此问的关键）
6. 问某年为什么没有某只票 → `--uncovered`（24 条行情源未覆盖）
7. 需要 K 线图/完整浏览 → 引导打开 `references/viewer/妖股年鉴_1990-2026.html`

## 检索工具

```bash
# 总览（KPI / 题材 / 年份跨度 / 数据质量）
python scripts/search_yaogu.py --stats

# 37 年一览（年份 | 年度标题 | 市场特征 | 最强妖股）
python scripts/search_yaogu.py --years

# 某年详情（年份卡 + Top12）
python scripts/search_yaogu.py --year 2015

# 全库涨幅排行
python scripts/search_yaogu.py --top 20
python scripts/search_yaogu.py --top 20 --from 2010 --to 2026

# 按题材 / 个股 / 关键词
python scripts/search_yaogu.py --theme 重组借壳 --top 10
python scripts/search_yaogu.py --code 300431
python scripts/search_yaogu.py --keyword 暴风

# 口径说明 / 修正榜 / 未覆盖明细
python scripts/search_yaogu.py --caliber
python scripts/search_yaogu.py --fix --top 10
python scripts/search_yaogu.py --uncovered

# 日线谷峰指标（420 组，含谷峰日期、价格、天数、偏差）
python scripts/search_yaogu.py --kline 2015|300431
```

## 输出规范

1. **每个涨幅数字都要带口径标签与年份**，格式示例：`暴风科技（300431）2015 年跨年谷→峰 +1,956%（历史实算）`
2. 数据来自 `yearbook.json`（v4 实算口径）时，若与 `database_v4.json`（v5 口径说明）字段不一致，
   以 `yearbook.json` 的 `gain/gainText/caliber` 为准，并说明差异来源
3. 提到"某年最强妖股"必须说明是按**实算口径**排序，非当年媒体口径；若用户拿网上数字对比，
   优先引导到 `--fix` 修正榜查是否属于被修正条目
4. 24 条未覆盖（多为 1990-1992 老股，如深发展 000001）要如实说明"行情源无有效数据，仅有原始记载值"，
   **不得编造实算涨幅**
5. 年份卡 2026 为"进行中"（数据截至 2026-11-05），引用时注明未完整年度

## 合规红线（本 skill 风险最高，必须严格执行）

- **禁止任何当前/未来指向**：不得回答"今年谁会成妖""现在哪只票有妖股相""这只票还能涨多少"
- **禁止把历史涨幅当收益承诺**：所有数字必须标注"历史实算，事后统计，不可复制"
- **禁止给买卖点**：不提供任何入场/出场/仓位建议，即使引用缠论或江恩框架也只讲历史结构
- **不评价当前个股**：用户问某只在交易中的股票，只能回答"本库仅含历史记录，不做当前评价"
- **数据免责**：所有输出结尾附免责声明；数据源为腾讯/新浪日线，未经审计，仅供参考
